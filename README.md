# MetaESG 🌱

Projeto acadêmico desenvolvido em **Java** com o objetivo de aplicar conceitos de desenvolvimento de software em uma solução relacionada a **ESG (Environmental, Social and Governance)**.

A aplicação foi estruturada utilizando o padrão **MVC (Model-View-Controller)** e possui interface gráfica desenvolvida com **JavaFX**.

## 📌 Objetivo

O projeto tem como objetivo apresentar e trabalhar informações relacionadas aos pilares de ESG:

- **Environmental (Ambiental)**
- **Social (Social)**
- **Governance (Governança)**

Além do tema de sustentabilidade, o desenvolvimento do projeto também teve como foco a aplicação prática de conceitos de programação orientada a objetos, organização de código e construção de interfaces gráficas utilizando Java.

## 💻 Tecnologias utilizadas

- Java
- JavaFX
- MVC
- Programação Orientada a Objetos

## 🏗️ Arquitetura

O projeto utiliza o padrão arquitetural **MVC**, separando as responsabilidades da aplicação em diferentes camadas:

### Model

Responsável pela estrutura e manipulação dos dados da aplicação.

### View

Responsável pela interface gráfica e interação com o usuário.

### Controller

Responsável pela comunicação entre a interface e as regras da aplicação.

Essa organização facilita a manutenção do código e mantém as responsabilidades de cada parte do sistema separadas.

## 🌎 ESG

ESG é uma abordagem utilizada para analisar aspectos ambientais, sociais e de governança de organizações e projetos.

Os três pilares são:

### 🌱 Environmental

Relacionado aos impactos ambientais, sustentabilidade e utilização responsável dos recursos naturais.

### 👥 Social

Relacionado às pessoas, sociedade, condições de trabalho, diversidade e responsabilidade social.

### 🏢 Governance

Relacionado à administração, transparência, ética e práticas de governança das organizações.

## ▶️ Como executar

Para executar o projeto é necessário possuir o **Java** instalado e um ambiente de desenvolvimento compatível com JavaFX.

Clone o repositório:

```bash
git clone https://github.com/Vitor99x/MetaESG.git
```

Acesse a pasta do projeto:

```bash
cd MetaESG
```

Depois, abra o projeto em uma IDE compatível com Java, como:

- IntelliJ IDEA;
- Eclipse;
- NetBeans.

Configure o **JavaFX**, caso necessário, e execute a classe principal da aplicação.
